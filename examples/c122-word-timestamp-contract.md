# C122 — word-timestamp transcription contract

This is a small, rights-safe contract for testing transcript timing before any integration or paid usage.

## Scope

- Input: an audio file the operator owns or is authorized to process.
- Output: transcript text, speaker/timestamp metadata when available, and SRT/VTT for human review.
- The route is a public demand-capture page: https://one-percent-lab.fabiosuizu.chatgpt.site/guides/c122-savvycal-postbooking-transcript
- No upstream account, token, OAuth grant, private upload, installation, or marketplace submission is required for the fixture.

## Boundary

The C122 page does not claim WhisperLive compatibility, word-level timestamp correctness, or an upstream partnership. It only measures whether a real operator reaches first value and then chooses the owned checkout.

If a maintainer opts in, the next artifact can be a small fixture matrix comparing cue/word boundaries and discarded-audio behavior. No PR or source change is made without an explicit request.

## Measurement

The attribution intent is c122|savvycal|post-booking-transcript|global. A CTA or checkout redirect is initiation only. Buyer-linked revenue requires a confirmed payment, settlement, payout, and bank reconciliation in the ledger.
