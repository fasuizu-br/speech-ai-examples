# C121 calendar and publisher workflow contract

This is an opt-in contract for a public demand experiment by BRAINIALL / Transcreve BR.

Candidate jobs:
- Calendly completed booking -> authorized transcript and follow-up
- Google Workspace Calendar meeting -> reviewed transcript/SRT
- Microsoft Graph calendar event -> activity follow-up
- Smartsheet or Wrike project update -> reviewed task/comment
- Dataverse activity -> CRM context
- beehiiv post/episode -> transcript and editorial repurpose

Safe boundary:
- No platform account, OAuth grant, token, tenant, subscriber list, private audio, or marketplace submission is requested.
- A public route and synthetic/authorized fixture are the only first step.
- The operator configures their own integration if a real trial is mutually agreed.
- A checkout redirect is initiation only. Revenue is counted only after payment, settlement, payout, and bank reconciliation.
